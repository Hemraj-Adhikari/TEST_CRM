#  CRM Software (Customer Relationship Management System)

##  Project Overview
This CRM Software is a web-based application designed to manage customer data, leads, and business operations efficiently.  
The system helps organizations track interactions, manage workflows, and improve productivity.

 Development Time: 2 Months  
 Developed By: Hemraj Adhikari

##  Key Features

-  Customer Management
-  Lead Tracking System
-  Dashboard & Analytics
-  Course / University Management
-  User Authentication & Authorization
- Task & Follow-up Management
-  Data Storage & Retrieval System
-  Fast and User-Friendly Interface
